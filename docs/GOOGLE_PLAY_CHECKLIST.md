Для Play-сборки сначала заполните `mobile/android/key.properties` по шаблону
`mobile/android/key.properties.example`, сохранив настоящий файл и keystore
вне Git. В PowerShell:

```powershell
$env:PLAY_STORE_RELEASE = "true"
flutter build appbundle --release
Remove-Item Env:PLAY_STORE_RELEASE
```

Без этого флага релизная сборка подписывается debug-ключом и предназначена
только для тестирования или существующего канала загрузки, но не для Play.
Пользователи Google Play обновляют приложение через магазин; встроенная проверка
не устанавливает поверх Play-версии APK из GitHub. Подробно о требованиях к
совпадению application ID и signing key — в
[официальной документации Android](https://developer.android.com/google/play/app-updates).
