# Telecom Manager Mobile

Автономное Android-приложение для учёта работы монтажника.

Сейчас доступны:

- локальная SQLite-база;
- провайдеры, склады и остатки;
- приход материалов;
- клиенты;
- подключения со списанием материалов;
- перемещения между складами;
- взаимные долги провайдеров по материалам с учётом возвратов;
- финансовая сводка и журнал операций;
- передача денег в офис, выплата офисом и корректировки;
- дополнительные работы со списанием материалов;
- расходы монтажника и офиса;
- управление провайдерами, складами, материалами и видами работ;
- полная история складских движений;
- очередь изменений для будущей синхронизации.
