# Telecom Manager Mobile

Android-приложение с автономной SQLite-базой и дополнительной синхронизацией
через сервер Telecom Manager.

## Возможности

- Dashboard с периодами, провайдерами, KPI, долгами и предупреждениями.
- Клиенты и подключения с поиском, фильтрами и историей.
- Атомарное списание и возврат материалов при изменении или удалении работ.
- Все складские операции, остатки по складам и межпровайдерские долги.
- Возвраты материалов между провайдерами.
- Финансовая сводка, журнал, расходы и расчёты с офисом.
- Дополнительные работы с несколькими материалами.
- Отчёты с экспортом в CSV, XLSX и PDF без интернета.
- Управление провайдерами, складами, материалами и видами работ.
- Локальные организации, пользователи, роли и пароли.
- Серверные организации для разных городов и приглашение участников.
- Двухсторонняя push/pull-синхронизация с защитой конфликтов.

## Автономная работа

После установки приложение создаёт отдельную локальную организацию. Все
операции сохраняются в SQLite и не требуют интернета. Обновление APK выполняет
миграцию базы без удаления существующих данных.

Первый локальный вход:

```text
Логин: admin
Пароль: 0000
```

## Подключение к серверу

1. Откройте вкладку «Синхронизация».
2. Введите HTTPS-адрес сервера, логин и пароль пользователя сайта.
3. Нажмите «Подключить устройство».
4. Если доступно несколько организаций, выберите нужную.
5. Нажмите «Синхронизировать сейчас».

Локальная организация и каждая серверная организация хранятся раздельно.

